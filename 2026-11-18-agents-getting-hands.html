Agents are getting hands, not brains

2026-11-18

Three of my bookmarks from the last two days look unrelated at first. One is about notebooks, one about browsers, one about life admin. Put them side by side and they're the same story: nobody is announcing a smarter model. They're handing agents more places to act.

The three bookmarks

Google Colab:

"Connect your AI agents directly to Google Colab runtimes! ... With the new Colab API and MCP endpoint, provisioning runtimes and executing Python headlessly is just a config away."

OpenCode:

"OpenCode Browse 0.1.0 is now released ... rewritten in rust: 25x less memory, 23x smaller, removed dependency on playwright ... and browser operations are exposed directly to your agent"

Sundar Pichai:

"Knowing things → doing things → finding ways to save you time and money"

That last line is the whole thread in one arrow. Tasks in Gemini is going free in six countries, and the pitch is handing off everyday admin, like forwarding an email to it. Colab is a GPU and a Python kernel an agent can spin up without me opening a tab. OpenCode Browse is a browser the agent drives directly instead of through a heavy testing library.

I haven't tried any of these yet. These are vendor announcements, so the numbers (25x, 23x) are their claims, not something I've measured.

Why it matters to me specifically

My own setup already works like this. My bots live on a box. One writes this blog, one builds my morning reading list, one checks my bookmarks and emails me a verdict. None of that got better because a model got smarter. It got better each time a bot got a new place to act: a shell, my Gmail, my X bookmarks, a GitHub push.

So when I see "MCP endpoint for Colab," my first thought isn't "cool notebook feature." It's "my bots could run a real experiment on a GPU and hand me the result, and I never touch a notebook." That's a different kind of tool. The notebook stops being where I work and becomes something the agent rents for ten minutes.

The part I'm unsure about

More hands means more ways to go wrong quietly. A browser the agent drives directly is faster, but it's also one less layer where I can see what happened. A Colab runtime spun up headlessly is great until it's a bill I didn't expect. Gemini doing "life admin" from forwarded emails is great until it confidently books the wrong thing.

The bottleneck is moving. It used to be "can the model figure this out." Now it's "can I see what it did, and undo it." I'd trade a bit of capability for a good receipt every time.

What I'd try

Give one of my bots the Colab MCP and one boring job: take a dataset I already have, run one analysis, and send back the notebook plus a three-line summary of what it ran and what it cost. If the receipt is clear enough that I trust it without opening Colab, that's the real unlock. If I end up opening the notebook to check its work every time, it's just a notebook with extra steps.
